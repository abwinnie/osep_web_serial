# 大象牙膏實驗噴發效果模擬遊戲

繁體中文、純瀏覽器的 Vite／TypeScript／Three.js 科學視覺化，支援十種催化劑／對照條件、RGB、3D 濃密泡沫、暫停繼續、歷史保存、濃度分組比較與 UTF-8 BOM CSV。無需帳號或後端。

## 與原儲存庫的關係

原儲存庫是 Scratch Web Serial，檢查工作樹、分支與提交訊息後未找到牙膏模擬或先前所述 3,595 顆／119 單位的程式。此應用新增於獨立子目錄，保留原始 Scratch 程式與套件。無法證實恢復了不存在於此 checkout 的歷史效果；以下數據是新建立的回歸基準。

## 本機開發

使用 Node.js 22（此應用不可使用舊 Scratch 的 Node 14）：

```sh
cd elephant-toothpaste
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`build` 包含 TypeScript 嚴格型別檢查。`test` 以固定種子、60 Hz 步進驗證 30% H₂O₂＋10% KI 的數量、高柱、擴散與落地、零邊界、10 種物質、濃度分組、快照、去重、CSV 及儲存資料驗證。瀏覽器測試另見 `test/browser.cjs`；需可用的 Playwright 與 Chromium，執行方式如下：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/usr/bin/chromium node test/browser.cjs
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/usr/bin/chromium node test/estimates-browser.cjs
```

測試需先啟動開發伺服器，預設 5173；可設定 `TEST_URL` 測試正式建置的子路徑。實際結果見 [TEST-RESULTS.md](TEST-RESULTS.md)。瀏覽器驗證實際等待兩次模擬完成，不使用假的完成事件。截圖與 CSV 輸出至作業系統暫存目錄。

## 模組

- `src/catalysts.ts`：十種物質、物態／濃度基準、證據及限制。
- `src/model.ts`：示意速率、進度與獨立固定步進粒子模型。
- `src/foam-surface.ts`：細密泡沫外觀、圓頂與連續粗條；固定拓撲與可重用頂點緩衝，不改變反應統計或紀錄。
- `src/foam-motion.ts`：依使用者提供影片中的頂端彎折、下垂、接地折疊建立分段材料鏈；120 Hz 固定步長、段長約束、重力、自接觸與量筒／地面碰撞。下段依序失去支撐，瓶口保留連接；24 秒後保留堆積，不依時間縮小。此為示意視覺模型，不能精確重現影片或預測真實泡沫。
- `src/cylinder.ts`：100 mL 直筒量筒、開口、底座、10–100 mL 刻度與容量對應液面。
- `src/scene.ts`：場景、100 mL 透明量筒、固定底部液面、實例化泡沫與 OrbitControls。
- `src/estimates.ts`：化學計量及未校準的體積／質量示意假設。
- `src/history.ts`：不可變快照、本機資料驗證、去重及分組。
- `src/csv.ts`：全歷史與分組 CSV，保留未估算欄位。
- `src/main.ts`：控制項與單一歷史來源的表格／圖表同步。

## 模型與動畫基準

固定名目液體體積 100 mL、16 秒模擬。相對速率＝示意係數 × √（名目催化劑百分比 / 10）×（H₂O₂ 百分比 / 30）。輸入 30 代表 30%，不是 0.3%。進度使用 `1-exp(-rate*t/4)`，無單位，未以實驗校準。零 H₂O₂ 或零催化劑時忽略自然分解，不噴發。鐵／銅鹽採同一示意係數，不宣稱精確差異或普遍排名；對照物質保留示意非零影響。

泡沫發射率、重力、擾動與粒徑為獨立動畫參數。固定種子與 60 Hz 步進讓更新頻率不影響回歸結果；粒子上限 6,000，單次最大生成約 6,000 顆，重新開始替換本次粒子，不無限累積。完成後統計快照固定；畫面中的過高柱身會側傾坍塌，殘餘泡沫繼續落地並形成較厚的堆積。完成後固定保留同一批泡沫，不再自動縮小或消失，直到使用者明確開始新一次模擬或停止本次。30%＋KI 10% 的新基準約 3,600 顆、最高 127.3 場景單位，非真實量測。這不是重建既有版本的證據。

液面下降最多 7.5 場景單位，由上方下降、底部固定；只是進度視覺化。體積／質量改採 `foam-scenario-1.0` 示意估算：名目 H₂O₂ 視為 w/w%，溶液與液相密度假設 1 g/mL，依 2 H₂O₂ → 2 H₂O + O₂ 與反應進度計算氧氣；25°C／1 atm 下氣體莫耳體積取 24,465 mL/mol，假設捕捉 15% 氧氣、目標液相體積比例 2%，且夾帶液體上限為剩餘液體質量的 50%。體積為捕捉氣體加夾帶液體（mL），質量為捕捉氧氣加夾帶液體（g），未計催化劑添加量及熱效應。所有假設均未實驗校準，會隨新紀錄快照保存；與動畫粒子數無關。舊紀錄的 null 值保留「未估算」，不回填、不冒充當時估算。w/w% 的溶液定義為溶質質量除以溶液總質量；MnO₂／酵母採懸浮混合物名目質量百分比，不假設溶解，也不假設 100% 均能形成水溶液。

每次按開始後會保存當時參數，完成才新增一次紀錄。暫停不產生紀錄；重新開始捨棄未完成的動畫，重設只改控制值；兩者都保留歷史。顏色可即時改變觀察畫面，歷史 RGB 保留開始時的設定。比較直接由歷史依 H₂O₂ 濃度分組，保留每筆不同催化劑濃度；提醒時間、進度、版本或濃度差異，沒有另一份手動比較清單。

## 資料保存

使用 `localStorage` 鍵 `elephant-toothpaste.history.v1`，只存在目前瀏覽器／來源，不提供跨使用者或跨裝置同步。重新整理會恢復，瀏覽器清除資料可能遺失。格式不相容／損毀時保留原始儲存值，不靜默覆寫；儲存空間不足時顯示錯誤，仍可匯出記憶體內紀錄。CSV 含唯一 ID、完整快照、模型版本及限制，UTF-8 BOM 配合 CRLF 與欄位引號便於 Excel 開啟。

## GitHub Pages

`vite.config.ts` 使用 `base: './'`；沒有前端路由，靜態資源可從儲存庫子路徑載入，重新整理不依賴路由回退。

1. 將變更推送到 GitHub 的 `master`（其他預設分支請調整工作流程觸發條件）。
2. 在儲存庫 Settings → Pages → Source 選擇 **GitHub Actions**。
3. 執行 `.github/workflows/elephant-pages.yml`：Node 22、`npm ci`、測試、型別檢查與建置，保留既有 `app` 靜態網站於網站根目錄，再將 `elephant-toothpaste/dist` 放入 `/elephant-toothpaste/` 子目錄後部署。
4. 等工作流程成功後，以實際輸出的 Pages 網址驗證頁面、資源回應、重新整理與保存／匯出功能。

**牙膏應用的公開路徑為 `https://<帳號>.github.io/<儲存庫>/elephant-toothpaste/`。** 原 Scratch 原始碼與已追蹤的 `app` 保留，部署產物亦保留原 `app` 在根目錄。先前版本已由 GitHub Actions 成功發布。每次更新仍須確認對應工作流程成功；本機建置不代表新版已上線。

## 科學與安全聲明

本網站為電腦視覺化模擬，所有反應速率、泡沫高度、體積及質量均依模型假設產生，不代表真實實驗的精確預測。不同催化劑的模擬結果不可直接視為經實驗證實的催化能力排名。真實化學實驗須由合格教師或專業人員依適當的實驗室安全規範進行。

本網站不提供真實高濃度過氧化氫的配製、混合或操作步驟。機制參考 RSC Education 的 Elephant’s toothpaste，並未引用其操作量或視為模型校準資料；酵母與異相催化為一般機制說明，模型係數完全屬示意假設。

## 參考圖直立泡沫柱外觀

預設「直立粗泡沫柱」使用連續曲面與微泡凹凸紋理：垂直粗柱、圓潤頂端、略微外擴的底部及不對稱的側邊鼓起，不再使用鉤狀彎折。容器為 100 mL 量筒；噴發結束先保持直立，過高的柱身會漸進側傾、頂端彎下並移向地面堆積；短粗柱不強制坍塌。可按「參考圖奶油黃」同步設定 RGB，再用「近看量筒與泡沫」觀察。外觀選單仍提供「原始粒子觀察」。粒子模擬與統計持續運算，但乳霜模式以連續表面包覆呈現，不把每顆模擬粒子畫成獨立球體；畫面曲面不是額外的化學體積或質量。

此改動僅影響外觀，不修改反應參數、既有歷史或估算模型。網格頂點緩衝重用，紋理及幾何體在離開頁面時清理。乳霜流動與彎折為視覺近似，未實作流體力學或真實泡膜求解器，不宣稱與照片完全相同。

瀏覽器外觀回歸：`PLAYWRIGHT_MODULE=/path/to/playwright TEST_URL=<測試網址> node test/foam-browser.cjs`。

## 100 mL 量筒與完成後坍塌

容器改為 100 mL 透明直筒量筒，包含開口、穩定底座、10–100 mL 刻度與 5 mL 分隔線。初始名目 100 mL 的液面對齊 100 mL 刻度；反應中液面下降仍是視覺估算，不宣稱為實測剩餘液量。液體底部固定於量筒內底，不隨液面等比例縮放。

坍塌是獨立外觀模型：完成噴發後保留約兩秒直立期，再依柱高／名目直徑的相對指標由最高點先下塌；失穩前緣逐段往下傳遞，下方在前緣抵達前不動。原柱身的同一批曲面頂點連續下落，約 24 秒在瓶旁形成堆積。移除了原本依落地粒子數另外放大的地面泡沫塊，地面不再自行冒出新的泡沫。只有原曲面接近地面時，才依局部線段的壓縮程度壓扁、向外攤開；不另外生成地面泡沫塊。這不是經實驗驗證的失穩門檻或流體求解；最高高度、模型進度、體積／質量與歷史快照不會被沉降動畫回寫。畫面會顯示直立觀察、側傾、坍塌及堆積完成狀態，亦不因這些更新重複新增紀錄。

## 落下後持續保留

泡沫仍由最高點開始逐段坍塌，同一曲面落至量筒旁形成圓潤、較厚的折疊堆積；沒有地面獨立生成泡沫。移除時間造成的半徑縮減，完成後形狀固定，乳霜與原始粒子兩種模式均保留泡沫。長時間保留是外觀操作選擇，不代表真實泡沫永不消散；歷史與體積／質量估算不會因此改寫。

初始液量為 10 mL（容量 100 mL），液面對齊 10 mL 刻度；下降量不超過初始液深 80%。剛噴出泡沫的曲面半徑限制在量筒內半徑 3.05 以內；接地才因折疊而堆積。移除舊版獨立瓶口泡沫環，保留透明玻璃口緣。
