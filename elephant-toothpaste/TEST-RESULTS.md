## 限制

- 原始工作樹、可用分支及 Git 歷史未找到既有牙膏應用，無法進行舊版 3,595 顆／119 單位畫面的逐幀比較。
- 先前版本已由 GitHub Actions 成功發布；新版部署須另外檢查對應工作流程。公開站直連受環境網路限制，未以遠端公開頁面渲染結果作為本文件測試證據。
- 手機測試是 390px Chromium 響應式測試，尚未以實體手機量測 FPS 或驗證 Safari。
- 模型未經化學實驗校準；新版體積／質量採明列假設的示意估算，不提供真實催化能力排名。
- 瀏覽器儲存限於本機來源，未實作雲端同步。
